# Portfolio site
Personal site served by GitHub Pages at https://zakkyhidayat.github.io (Deploy from branch: `main` / root). Edit projects in `assets/js/projects.js`; every push to `main` redeploys.

## Adding a project
Copy an entry in `assets/js/projects.js` and fill it in (title, summary, icon, platform, `version`, tags, and `repo` / `download` / `live` links where they exist). Versions are written by hand: bump `version` when you publish a release. Leave `repo` empty for private repositories.

Fonts are self-hosted in `assets/fonts` (Plus Jakarta Sans, SIL Open Font License, see `OFL.txt`).
